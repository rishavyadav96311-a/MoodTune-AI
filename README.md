# MoodTune AI — Personalized Music Recommendation Prototype

GitHub-ready prototype for the **AI-Powered Personalized Music Recommendation System**, Group 20, GNIOT.

## Features
- Responsive music recommendation dashboard
- Browser camera preview
- Manual emotion selection
- Lightweight text sentiment detection
- Emotion-specific playlist recommendations
- Confidence display
- Architecture: Data Input → Emotion Detection → Recommendation Engine → Playlist

## Prototype note
The camera analysis is a demo-stage simulation. The presentation proposes CNN/LSTM emotion models, FER-2013/RAVDESS, Spotify Web API, Flask/Node.js, React/Flutter and cloud deployment for the production version.

## Run locally
Open `index.html`, or use `python -m http.server 5500`.
